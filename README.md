# ⚡ JavaScript — My Learning Journey

Welcome to my JavaScript repository! This repository tracks my JavaScript learning journey throughout my four years of B.Tech, from programming fundamentals to interactive web development and practical projects.

It includes the code I write in class, the exercises I solve independently, my assignments, and the projects I build as I improve my skills.

## 📚 What This Repository Contains

- **Classwork:** Lecture examples, programs, and concepts taught in college.
- **Self-Practice:** Independent exercises to improve coding skills and understanding.
- **Assignments:** Faculty-assigned programs and practical tasks.
- **Problem Solving:** Logical problems involving variables, conditions, loops, arrays, strings, and functions.
- **Concepts & Notes:** JavaScript syntax, data types, operators, objects, functions, scope, and other important topics.
- **DOM & Web Development:** Practice with the Document Object Model, events, and interactive web pages.
- **Test Preparation:** MCQs, practice questions, and revision material for college assessments.
- **Error Rectification:** Incorrect test questions, corrected answers, and explanations of concepts I need to revisit.
- **Projects:** JavaScript applications and web development projects.

## 🎯 My Learning Goals

- Strengthen JavaScript fundamentals.
- Improve logic-building and debugging skills.
- Understand how JavaScript makes websites interactive.
- Write readable, maintainable code.
- Apply concepts through assignments and practical projects.
- Learn from errors and improve through consistent practice.
